# 📚 Study Session Tracker

A command-line Python application for recording and reviewing study sessions.

## ✨ Features

- Record a study session
- Enter the subject being studied
- Enter the topic being studied
- Record the duration of the session
- Record the date of the session
- View complete study session history
- View today's study summary
- View weekly study summary
- Interactive menu-based interface

## 🛠️ Concepts Used

- Variables and user input
- Functions
- Dictionaries
- Lists
- Loops
- Conditional statements
- `datetime`
- `timedelta`

## ▶️ How to Run

Make sure Python is installed on your system.

Open a terminal in the project folder and run:

    python study_session_tracker.py

Follow the instructions displayed in the terminal.

## 📋 Menu

    1. Start a new study session
    2. View all study session history
    3. Today's study summary
    4. Weekly study summary
    5. Exit

## 📊 Recorded Information

| Information | Description |
|---|---|
| Subject | The subject being studied |
| Topic | The specific topic being studied |
| Duration | Study duration in minutes |
| Date | Date of the study session |

## 🧠 How It Works

The program uses an interactive command-line menu to manage study sessions.

A user can record a session by entering the subject, topic, duration, and date. Recorded sessions can then be viewed through the history, daily summary, and weekly summary options.
